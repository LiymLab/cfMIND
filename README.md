## cfMIND: A read-level methylation framework for accurate non-invasive disease detection using cell-free DNA
cfMIND  (<em><u>cf</u></em>DNA <em><u>M</u></em>ethylation signals of <em><u>IN</u></em>dividual read for disease <em><u>D</u></em>etection) is a **machine learning-based framework** that enables identification of stratified cfDNA methylation signals at the **individual read level** for sensitive and robust disease detection.

## 🌟Installation 
cfMIND requires both **Python** and **R** environments. For stable performance, we recommend:

- **Python**: 3.7.12 
- **R**: 4.3.2

You can set up your conda environment and install the required R packages as follows:

```bash
git clone https://github.com/LiymLab/cfMIND.git
chmod a+x -R ./cfMIND
cd cfMIND
conda env create -f environment.yml
conda activate cfMIND
Rscript install_packages.R
```

## 📂Data Preparation

To get started with **cfMIND**, please prepare the following files:

1. **BAM files**
   - Generated by Bismark alignment.
   - Coordinate-sorted and indexed (`.bam` with corresponding `.bai`).
2. **CpG_OB/T files** corresponding to each BAM file:
   - **CpG_OB\***: methylation information for CpGs on the *original bottom strand (OB)*.
   
     **CpG_OT\***: methylation information for CpGs on the *original top strand (OT)*.

**Tip:** Generate CpG_OB/OT with **Bismark methylation extractor**: ([Bismark GitHub](https://github.com/FelixKrueger/Bismark)):

```bash
bismark_methylation_extractor sample.name_sorted.bam -o /path/to/output/ --bedGraph --counts --no_overlap --genome_folder /path/to/hg38
```
Once the installation and data preparation are complete, you are ready to start cfMIND. ✌️

## 🚀Quick Start

The main script **`cfMIND.sh`** supports **two major steps**:

1. **Feature extraction** – extract cfDNA methylation features from BAM and CpG files.

2. **Disease detection** – train and evaluate the model using cross-validation.

To help you verify your environment setup and quickly get started with cfMIND, we provide **example files** on Zenodo: https://doi.org/10.5281/zenodo.17067679.

You can run cfMIND with:

```bash
bash cfMIND.sh feature_extraction -m manifest.txt -r hg38 -c 20 -p test -o /output/dir -@ 10
bash cfMIND.sh disease_detection -d feature_matrix.txt -p test -o /output/dir -n 1 -k 5 -@ 5
```

## 🍳Workflow

cfMIND provides a streamlined **two-step workflow** for non-invasive disease detection:

1. **Feature Extraction**: Processes BAM and CpG files to extract read-level methylation features from specified genomic regions, generating a feature matrix with methylation patterns at different levels (0%, 25%, 50%, 75%, 100%).

2. **Disease Detection**: Uses the extracted features to train an XGBoost machine learning model with cross-validation, providing prediction probabilities and comprehensive evaluation metrics for disease classification.

### **1. Feature Extraction**
This step extracts stratified cfDNA methylation signals from BAM and CpG files using a manifest file.

```bash
bash cfMIND.sh feature_extraction -m manifest.txt -r hg38 -c 20 -p test -o /output/dir -@ 10 --cfTAPS
```

#### Options:

```txt
-m: Manifest file (tab-delimited, with header). Must contain columns:
    - bam: Input BAM file (sorted & indexed)
    - cpg_ob: CpG_OB* file (bottom strand) from bismark methylation extractor
    - cpg_ot: CpG_OT* file (top strand) from bismark methylation extractor
    - prefix: Output prefix for each sample
    - label: Sample label (required for disease detection)
-r: BED file of genomic regions. Can use 'hg38' or 'hg19' as shortcuts,
    or provide a custom BED file path (4 tab-delimited columns, no header):
    Example: <chromosome> <start> <end> <region_id>
             chr1       10000    10500  region_21
-c: Coverage cutoff threshold (default: 20)
-p: Output prefix for processed data (default: test)
-o: Output directory (default: current working directory)
-@: Threads for parallel processing (default: 1)
--cfTAPS: Use this option for cfTAPS sequencing data
```

#### Manifest File Format
The manifest file should be a tab-delimited text file with header containing the following columns:

**Note:** Downstream evaluation metrics are calculated assuming `CTR` is the first level of the `label` column.

```txt
bam	cpg_ob	cpg_ot	prefix	label
/path/to/sample1.bam	/path/to/CpG_OB_sample1.txt	/path/to/CpG_OT_sample1.txt	sample1	CTR
/path/to/sample2.bam	/path/to/CpG_OB_sample2.txt	/path/to/CpG_OT_sample2.txt	sample2	Tumor
```

#### Output
cfMIND.sh feature_extraction produces CSV files for each sample and then processes them into a feature matrix file with integrated labels.

- **Individual CSV files** – `/output/dir/sample.csv` for each sample
- **Feature matrix file** – `/output/dir/feature_matrix.txt` (processed feature matrix with label column, used for disease detection)
- **Region selection log** – `/output/dir/region_selection.log` (filtering and selection details)
- **Coverage distribution plot** – `/output/dir/coverage_distribution.png` (coverage statistics visualization)

**CSV file columns:**

- **region** – Genomic region ID.
- **0, 0.25, 0.5, 0.75, 1** – Read counts at each methylation level (0%, 25%, 50%, 75%, 100%) .

Example:

```txt
region,0,0.25,0.5,0.75,1
region_21,0,0,0,0,2
region_1734,0,0,0,1,2
region_1741,2,4,2,1,0
```

**Region selection log:**

Example:

```txt
Common regions: 60604 
Regions retained after Coverage > 20 filter: 34510
```

**Feature matrix format:**

The feature matrix is a tab-delimited file where each row represents a sample and each column represents a methylation feature for a specific region and methylation level.

**Column naming convention:**
- Format: `region_<ID>_M_<methylation_level>`
- `<ID>`: Genomic region identifier (e.g., 1, 2, 3, ...)
- `<methylation_level>`: Methylation level (0, 0.25, 0.5, 0.75, 1)

**Structure:**
- **First column**: Sample names (matching the `prefix` column in manifest file)
- **Remaining columns**: Normalized feature values for each region-methylation level combination

**Complete example:**

```txt
	region_1_M_0	region_1_M_0.25	region_1_M_0.5	region_1_M_0.75	region_1_M_1	region_2_M_0	region_2_M_0.25	region_2_M_0.5	region_2_M_0.75	region_2_M_1	label
sample1	0.2	0.3	0.9	0.2	0.5	0.1	0.0	0.4	0.3	0.2	CTR
sample2	0.1	0.2	0.7	0.4	0.3	0.0	0.1	0.2	0.5	0.4	Tumor
sample3	0.3	0.1	0.5	0.6	0.2	0.2	0.2	0.3	0.1	0.3	CTR
```

**Key points:**
- Each sample has one row with features from all selected genomic regions
- Features are ordered by region ID, then by methylation level (0, 0.25, 0.5, 0.75, 1)
- The last column contains the sample label (from manifest file's `label` column)
- Values represent normalized read counts (per 10 million reads) at each methylation level for each region
- Missing or low-coverage regions are filtered out during processing
###  **2. Disease detection**

This step uses the extracted features to train and evaluate the model with cross-validation. It requires the feature matrix file from feature extraction that contains both features and labels. Example command:

```bash
bash cfMIND.sh disease_detection -d test_feature_matrix.txt -p sample_prefix -o /output/dir -n 10 -k 5 -@ 5
```

#### Options:

```txt
-d: Feature matrix file from feature_extraction step (e.g., feature_matrix.txt)
    This file should contain both the feature matrix and labels
-p: Output prefix (default: test)
-o: Output directory for prediction results (default: current working directory)
-n: Number of repeats for cross-validation (default: 1)
-k: Number of folds for cross-validation
    (default: number of samples in data, i.e. Leave-One-Out CV)
-@: Threads for parallel cross-validation (default: 1)
```



#### Output

- `<prefix>_XGBoost_predict_probability.txt`: Sample predictions with probabilities.

- `<prefix>_XGBoost_predict_metrics.txt`: Summary of evaluation metrics for each repeat.

  - For **binary classification**: AUC, accuracy, precision, recall, F1 score, and sensitivity at 90% specificity.
  - For **multi-class classification**: accuracy, precision, recall, and F1 score.

  Example:

  ```txt
  Repeat	AUC	Accuracy	Precision	Recall	F1	Sensitivity_at_90_Specificity
  1	0.888	0.853	0.894	0.790	0.839	0.790
  2	0.909	0.831	0.804	0.860	0.831	0.744
  ```

✅ With only two streamlined steps, **cfMIND** empowers users to capture read-level methylation features and achieve  sensitive, non-invasive disease detection.
